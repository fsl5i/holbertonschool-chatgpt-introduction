# ChatGPT - Introduction Project

This project is part of the Holberton School curriculum and introduces the use of ChatGPT for debugging and automating coding tasks.  
You will learn how to leverage AI tools to identify errors, correct code, and generate boilerplate scripts to improve productivity and understanding.

## Project Structure
- **debugging/** – Contains tasks focused on identifying and fixing issues in existing code.
  - `factorial.py`: A corrected Python script that computes the factorial of a number.

## Learning Objectives
- Understand how to use ChatGPT to detect logical and runtime errors.
- Apply AI assistance to improve debugging efficiency.
- Automate repetitive coding tasks using ChatGPT-generated code.
- Validate and verify AI-produced content.

## Requirements
- All code must follow Python best practices.
- Files must be executable.
- All commits must be pushed to the GitHub repository.
